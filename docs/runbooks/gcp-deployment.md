# ARCHIVED / UNSUPPORTED: GCP 배포

> 이 문서의 기존 GCP/SQLite 배포 절차는 현재 PostgreSQL Compose, role 분리, explicit migration, backup artifact 계약과 호환되지 않아 폐기되었다. 운영 또는 새 GCP 배포에 복사해 실행하지 말라.

GCP는 현재 지원 범위가 아니다. 현재 지원되는 절차는 [Oracle Always Free PostgreSQL 배포 실행서](oracle-deployment.md)와 [PostgreSQL 백업과 복구](backup-restore.md)를 따른다. GCP 지원을 다시 열려면 현재 Compose와 PostgreSQL 안전 계약을 기준으로 별도 설계·검증해야 한다.
