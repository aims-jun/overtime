# 근무 날짜 입력 너비 수정 설계

## 문제

추가 근무 등록·수정 모달의 `input[type="date"]`는 일부 모바일 브라우저에서 네이티브 날짜 UI의 고유 최소 너비를 유지한다. 현재 공통 `width: 100%`, `min-width: 0`, `max-width: 100%`만으로는 입력창이 `.field-wide`의 내부 너비를 초과하려는 현상을 완전히 차단하지 못한다.

## 설계

- `근무 날짜` 입력에 `work-date-input` 클래스를 부여한다.
- 전용 클래스에 `display: block`, `inline-size: 100%`, `min-inline-size: 0`, `max-inline-size: 100%`, `overflow: hidden`을 적용한다.
- 네이티브 `type="date"`와 브라우저 날짜 선택 기능은 그대로 유지한다.
- 공통 input 스타일이나 시간 선택 UI는 변경하지 않는다.

## 검증

- CSS 회귀 테스트가 날짜 입력 전용 너비 제한을 확인해야 한다.
- 웹 전체 테스트·린트·빌드가 통과해야 한다.
- 320px, 360px, 390px, 430px에서 모달 내부 폼·필드·날짜 input의 좌우 좌표를 측정한다.
- 모든 너비에서 날짜 input의 왼쪽은 부모보다 작지 않고 오른쪽은 부모보다 크지 않아야 하며 문서 가로 넘침은 0px이어야 한다.
