# 관리자 홈 이동과 업무 연장 시간 표기 디자인

## 목표

관리자 계정은 개인 업무 연장 기록을 사용하지 않으므로 로그인 직후와 루트 경로 접근 시 관리자 화면으로 이동한다. 관리자 화면의 업무 연장 시간은 원시 분 숫자 대신 직원 화면과 같은 읽기 쉬운 시간 형식으로 표시한다.

## 역할별 라우팅

- 인증된 일반 직원이 `/`에 접근하면 기존 개인 업무 연장 화면을 표시한다.
- 인증된 관리자가 `/`에 접근하면 `/admin`으로 `replace` 이동한다.
- 로그인 화면에서 인증이 완료되면 기존처럼 `/`로 이동하고, 루트의 역할 분기가 관리자를 `/admin`으로 보낸다.
- 관리자에게 표시되는 `AIMS` 로고의 링크는 `/admin`을 가리킨다.
- 일반 직원이 `/admin`에 직접 접근하면 기존 403 안내를 유지한다.
- 관리자 화면을 표시하기 전에 개인 업무 연장 API를 요청하지 않는다.

역할 분기는 보호 레이아웃 내부의 인증 사용자 정보를 사용한다. 별도의 인증 상태나 백엔드 API는 추가하지 않는다.

## 시간 표기

기존 `formatMinutes` 함수를 모든 사용자 화면의 업무 연장 시간 표기에 재사용한다.

- `0` → `0시간`
- `30` → `30분`
- `60` → `1시간`
- `90` → `1시간 30분`

관리자 내역 표의 `추가 근무` 열은 `formatMinutes(record.durationMinutes)`를 사용한다. 관리자 전체 합계에서 사람이 읽을 수 있는 합계 아래에 중복으로 표시하던 원시 `N분` 값은 제거하고 `TOTAL EXTENDED` 보조 레이블로 교체한다. 직원 화면의 기존 시간 표기는 변경하지 않는다.

## 오류와 접근 제어

관리자 여부는 현재 세션의 `user.isAdmin` 값을 그대로 신뢰한다. 인증되지 않은 사용자는 기존처럼 로그인 화면으로 이동하며, 일반 직원의 관리자 URL 접근은 기존 접근 거부 화면으로 처리한다.

## 테스트

- 관리자 세션으로 `/`에 접근하면 `/admin`으로 이동하고 관리자 화면을 표시하는지 확인한다.
- 관리자 세션에서 개인 업무 연장 화면과 개인 업무 연장 API 요청이 발생하지 않는지 확인한다.
- 일반 직원은 기존 개인 화면을 계속 보고 `/admin` 접근 시 403을 받는지 확인한다.
- 관리자 내역의 `60분`이 `1시간`으로 표시되고 원시 `60분` 문구가 남지 않는지 확인한다.
- 기존 `30분`, `1시간 30분`, `0시간` 포맷 동작을 유지한다.

## 제외 범위

- 관리자가 자신의 개인 업무 연장 기록을 등록하는 기능
- 관리자 권한을 화면에서 추가하거나 제거하는 기능
- 백엔드 권한 모델 또는 세션 구조 변경
- CSV 파일의 시간 데이터 형식 변경
