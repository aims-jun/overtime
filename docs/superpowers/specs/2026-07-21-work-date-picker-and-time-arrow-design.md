# 근무 날짜 선택기 및 시간 화살표 정렬 설계

## 문제

- 추가 근무 등록·수정 모달의 `근무 날짜`는 브라우저 네이티브 `input[type="date"]`를 사용한다. 모바일 브라우저마다 표시와 최소 너비가 달라 모달 너비를 침범하거나 최근 내역의 월 선택기와 시각적으로 어긋난다.
- 시작 시간과 종료 시간 사이의 화살표는 문자 `→`라서 글꼴의 기준선과 여백에 영향을 받는다. 현재 영역의 가운데가 아니라 위쪽으로 치우쳐 보일 수 있다.

## 날짜 선택기

- 네이티브 날짜 input을 프로젝트 전용 `DatePicker`로 교체한다.
- 닫힌 상태의 입력 버튼은 최근 내역 조회의 `MonthPicker`와 동일한 높이, 테두리, 모서리, 배경, 포커스 효과와 달력 아이콘을 사용한다.
- 선택된 날짜는 `2026년 7월 21일` 형식으로 표시하고, 폼 상태에는 기존 API 형식인 `YYYY-MM-DD`를 유지한다.
- 버튼을 누르면 해당 날짜의 달력을 팝오버로 연다.
- 팝오버에는 이전 달·다음 달 이동, 요일 머리글, 날짜 버튼을 제공한다. 날짜를 선택하면 값이 바뀌고 팝오버는 닫힌다.
- 바깥 영역 클릭과 `Escape` 키로 닫을 수 있어야 한다.
- 팝오버와 트리거는 모달 내부 너비를 넘지 않아야 하며 모바일과 PC에서 같은 동작을 제공한다.

## 시간 화살표

- 문자 `→`를 공통 아이콘의 오른쪽 꺾쇠 SVG로 교체한다.
- 화살표 영역은 시간 select와 같은 48px 높이를 가지며 SVG를 가로·세로 중앙에 배치한다.
- 360px 이상에서는 두 시간 입력 사이의 정중앙에 놓는다.
- 359px 이하에서 시간 입력이 세로로 쌓이면 아이콘도 아래 방향으로 회전하고 두 입력 사이의 중앙에 놓는다.

## 관리자 월 선택기

- 관리자 `업무 연장 현황`의 네이티브 `input[type="month"]`를 기존 공통 `MonthPicker`로 교체한다.
- 최근 내역 조회와 동일한 표시 형식, 달력 아이콘, 연도 이동, 월 선택 팝오버를 사용한다.
- 선택 결과는 기존과 같은 `YYYY-MM` 값으로 관리자 검색 파라미터와 보고서 요청에 반영한다.
- 관리자 필터 안에서는 트리거가 필터 열 너비를 채우고, 팝오버가 필터 카드나 모바일 화면을 넘지 않아야 한다.
- 월 선택기 트리거와 직원 선택 `select`에는 `min-height`뿐 아니라 `height: 48px`을 명시해 네이티브 폼 컨트롤을 다르게 렌더링하는 브라우저에서도 실제 높이가 같아야 한다.
- 두 컨트롤의 상단과 하단 좌표 차이는 각각 1px 이내여야 한다.

## 관리자 직원 이름

- `직원별 합계`, 데스크톱 표, 모바일 카드의 직원 이름을 모두 15px의 굵은 본문으로 표시한다.
- 이메일은 11~12px의 옅은 보조 정보로 유지해 이름과 정보 계층이 분명해야 한다.
- 합계의 시간 값과 직원 이름이 서로 밀리지 않도록 양쪽 영역에 `min-width: 0`을 적용하고 긴 이름은 자연스럽게 줄바꿈한다.

## 접근성

- 날짜 트리거에는 `근무 날짜` 레이블을 연결하고 펼침 상태를 전달한다.
- 달력 팝오버는 날짜 선택 대화상자로 식별한다.
- 이전 달·다음 달과 각 날짜 버튼에는 읽을 수 있는 한글 접근성 이름을 제공한다.
- 키보드 포커스 표시를 유지한다.

## 검증

- `DatePicker` 컴포넌트 테스트로 열기, 월 이동, 날짜 선택, `Escape` 닫기를 검증한다.
- 추가 근무 폼 테스트로 네이티브 date input이 제거되고 선택 날짜가 기존 `YYYY-MM-DD` 값으로 반영되는지 검증한다.
- 화살표가 텍스트가 아닌 SVG이고 중앙 정렬 규칙을 사용하는지 회귀 테스트를 추가한다.
- 관리자 필터 테스트로 공통 월 선택기가 열리고 선택한 달이 검색 파라미터와 보고서 요청에 반영되는지 검증한다.
- 관리자 필터 스타일 테스트로 월 선택기 트리거와 직원 선택기가 모두 명시적 `height: 48px`을 사용하는지 검증한다.
- 관리자 집계, 데스크톱 표, 모바일 카드의 이름 스타일이 15px 굵은 본문으로 유지되는지 회귀 테스트를 추가한다.
- 웹 전체 테스트·린트·빌드를 실행한다.
- 실제 브라우저에서 320px, 360px, 390px, 430px 및 PC 너비를 확인한다. 날짜·월 트리거와 팝오버의 가로 넘침이 없어야 하며 화살표 중심과 양쪽 시간 입력의 수직 중심이 일치해야 한다. 관리자 월 선택기와 직원 선택기의 계산 높이는 모두 48px이고 상·하단 좌표 차이는 1px 이내여야 한다.
