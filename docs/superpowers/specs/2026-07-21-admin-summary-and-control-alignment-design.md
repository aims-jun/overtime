# 관리자 요약 및 폼 컨트롤 정렬 설계

## 목표

- 시작·종료 시간 사이의 화살표를 레이블이 아닌 48px 시간 입력 영역의 정중앙에 배치한다.
- 관리자 직원 선택기의 브라우저 기본 화살표를 서비스의 SVG 아이콘으로 교체하고 입력 영역 중심에 맞춘다.
- 최대 10명의 직원별 합계를 짧게 훑을 수 있도록 상위 3명 중심의 접이식 요약으로 바꾼다.

API, PostgreSQL 스키마, 보고서 요청 형식과 운영 데이터는 변경하지 않는다.

## 시간 화살표

`OvertimeForm`의 시작 시간과 종료 시간은 각각 레이블과 48px `select`를 가진다. 그 사이의 화살표는 독립된 48px 슬롯을 사용하고 시간 입력의 아래쪽 기준선에 맞춘다.

- 데스크톱과 가로 배치 모바일에서는 시작 `select`, 화살표 슬롯, 종료 `select` 순서를 유지한다.
- 화살표 슬롯은 `height: 48px`이며 SVG는 `display: block`과 중앙 배치를 사용한다.
- 레이블 높이와 레이블 아래 간격은 화살표 중심 계산에 포함하지 않는다.
- 시작 `select`, 화살표 슬롯, 종료 `select`의 `getBoundingClientRect()` 중심 Y 차이는 각각 1px 이하여야 한다.
- 359px 이하에서 시간 입력이 세로로 쌓일 때도 화살표 슬롯은 48px을 유지하고 SVG만 아래쪽으로 회전한다.

## 직원 드롭다운

네이티브 `select` 동작은 유지하되 브라우저마다 다른 기본 화살표 표현만 제거한다.

- 직원 `select`를 `admin-select-control` 래퍼로 감싼다.
- `select`에는 `appearance: none`과 오른쪽 아이콘 공간을 위한 패딩을 적용한다.
- 래퍼 안에 기존 `Icon name="chevron-down"`을 렌더링한다.
- 아이콘은 포인터 이벤트를 받지 않으며 `top: 50%`, `transform: translateY(-50%)`로 48px 입력 영역의 중앙에 놓는다.
- 아이콘 오른쪽 여백은 14~16px, 크기는 18px로 고정한다.
- 키보드 포커스, 네이티브 옵션 목록, 값 변경 계약은 현재와 동일하게 유지한다.
- 아이콘과 `select`의 중심 Y 차이는 1px 이하여야 한다.

## 직원별 합계

직원 수는 최대 10명으로 가정한다. 현재처럼 모든 직원을 항상 세로 목록으로 표시하지 않고, 연장 시간이 많은 상위 3명을 먼저 보여준다.

### 기본 상태

- 제목은 `직원별 합계`를 유지하고 오른쪽에 전체 인원 `N명`을 표시한다.
- 직원 합계는 `totalMinutes` 내림차순으로 정렬한다.
- 시간이 같으면 원래 API 응답 순서를 유지해 화면 순서가 불필요하게 흔들리지 않도록 안정 정렬한다.
- 각 행은 순위, 직원 이름, 합계 시간으로 구성한다.
- 기본 상태에서는 최대 3개 행만 표시한다.
- 직원이 3명 이하이면 전체 보기 버튼을 렌더링하지 않는다.

### 펼친 상태

- 직원이 4명 이상이면 목록 아래에 `전체 N명 보기` 버튼을 표시한다.
- 버튼을 누르면 별도 모달이나 페이지 이동 없이 같은 카드 안에서 최대 10명을 모두 보여준다.
- 펼친 상태의 버튼 문구는 `접기`로 바뀐다.
- `aria-expanded`와 목록을 가리키는 `aria-controls`를 제공한다.
- 접으면 다시 상위 3명만 표시한다.

### 빈 상태

직원별 집계가 없으면 순위 목록과 펼치기 버튼 대신 `집계된 직원이 없습니다`를 표시한다.

## 레이아웃과 반응형 동작

- 전체 업무 연장과 등록 건수는 상단의 두 요약 영역으로 유지한다.
- 직원별 합계는 두 숫자 요약 아래의 독립된 전체 너비 영역으로 분리한다.
- 넓은 화면에서는 직원 행을 한 열로 표시해 순위와 시간 비교가 흔들리지 않도록 한다.
- 모바일에서도 순위·이름·시간은 한 행을 기본으로 유지한다.
- 긴 이름에는 `min-width: 0`과 `overflow-wrap: anywhere`를 적용하고 합계 시간은 줄바꿈하지 않는다.
- 목록이 펼쳐져도 카드 내부에서만 높이가 늘어나며 가로 스크롤은 만들지 않는다.

## 컴포넌트 경계

### `OvertimeForm`

시간 값과 제출 동작은 그대로 두고 화살표 슬롯의 정렬 계약만 강화한다.

### `AdminFilters`

직원 선택 값과 `onChange({ month, userId })` 계약은 유지한다. `select`와 아이콘을 묶는 표시용 래퍼만 추가한다.

### `AdminSummary`

내부에 펼침 상태를 갖는다. `report.totalsByUser`를 복사해 안정적으로 정렬하고, 기본 3명 또는 전체 목록을 파생해 렌더링한다. 서버 데이터는 수정하지 않는다.

## 접근성

- 시간 화살표와 드롭다운 장식 아이콘은 `aria-hidden="true"`로 처리한다.
- 직원 선택기는 기존 `직원` 레이블과 네이티브 키보드 동작을 유지한다.
- 전체 보기 버튼은 현재 펼침 상태를 `aria-expanded`로 전달한다.
- 순위 목록은 의미가 유지되도록 순서 있는 목록 `ol`을 사용한다.
- 버튼 포커스 스타일은 기존 공통 규칙을 따른다.

## 테스트 및 검증

- `OvertimeForm` 테스트에서 시간 화살표가 48px 슬롯이고 중앙 배치 규칙을 갖는지 확인한다.
- 브라우저 실측에서 두 `select`와 화살표 슬롯의 계산 높이가 모두 48px이고 중심 Y 차이가 1px 이하인지 확인한다.
- `AdminFilters` 테스트에서 기본 화살표 제거, 오른쪽 패딩, SVG 아이콘 렌더링을 확인한다.
- 브라우저 실측에서 직원 선택기와 꺾쇠 아이콘 중심 Y 차이가 1px 이하인지 확인한다.
- `AdminSummary` 테스트에서 상위 3명 정렬, 전체 보기, 접기, 3명 이하 버튼 미표시, 빈 상태를 확인한다.
- 320px, 360px, 390px, 430px, 1280px에서 가로 오버플로가 없는지 확인한다.
- 웹 전체 테스트, 린트, 프로덕션 빌드를 실행한다.
- 운영 배포 전 PostgreSQL 백업을 생성하고 웹 컨테이너만 재빌드·기동한다.
