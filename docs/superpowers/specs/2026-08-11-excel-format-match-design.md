# 관리자 Excel 내보내기 — 사내 표준 양식 일치 설계

## 목표

관리자 [Excel 다운로드] 결과물을 사내에서 쓰는 표준 파일(`연장 근무 이력_IT개발팀_2606.xlsx`)과 같은 양식으로 만든다. 데이터 범위는 **관리자가 선택한 월만** 담고, 양식(시트 구성, 컬럼, 스타일, 서식, 수식)은 표준 파일과 일치시킨다.

기준 파일 분석 결과와 이 설계의 결정 사항:

| 결정 | 선택 |
| --- | --- |
| 데이터 범위 | 선택한 월만. No.는 1부터 다시 시작 |
| 집계 시트 | exceljs는 진짜 피벗을 안정 지원하지 않으므로 같은 모양의 정적 값 표로 재현 |
| 부서 값 | 환경변수 `REPORT_DEPARTMENT` (기본값 `IT개발팀`) |
| 근무 유형 | 근무일이 토/일이면 `휴일근로`, 평일이면 `연장근로` (공휴일 미반영) |
| 주차 | 기준 파일의 수식은 연도 오타 버그가 있으므로 서버가 값으로 계산해 기록 |
| 30분 단위 | `연장근무`(L열)에 0.5 단위 그대로 기록 |
| 구현 방식 | 템플릿/zip 수술이 아닌 exceljs 프로그래밍 방식 생성 |

## 파일

- 파일명: `연장 근무 이력_{부서}_{YYMM}.xlsx` (예: 2026-08 → `연장 근무 이력_IT개발팀_2608.xlsx`)
- 한글 파일명은 `Content-Disposition: attachment; filename="overtime-YYMM.xlsx"; filename*=UTF-8''<percent-encoded>` 형태(RFC 5987)로 내려 ASCII fallback을 함께 제공한다.
- 시트 순서: `집계`, `연장근무 이력`, `기준` (기준 파일과 동일)
- 공통 글꼴: 맑은 고딕

## 시트 1: 연장근무 이력

### 레이아웃

- 1행(높이 23): A1 `연장근무이력 관리`, bold 16pt
- 2행: 빈 행
- 3행(높이 19): 헤더. 12pt, 가로/세로 가운데, 배경 `FFD9E1F2`(기준 파일의 theme4 tint 0.8에 해당), thin 테두리. K3·L3은 bold + 글자색 `FF0000FF`
- 4행부터 데이터. 10pt
- 틀고정: xSplit 5, ySplit 3 (A~E열, 1~3행 고정), zoomScale 140
- autoFilter: `A3:T{마지막 데이터 행}`

### 컬럼 (A~T)

| 열 | 헤더 | 값 | 서식/스타일 |
| --- | --- | --- | --- |
| A | `No. ` (뒤 공백 포함, 기준 파일 그대로) | 1부터 증가 | |
| B | 월 | `{YY}년 {M}월` (예: `26년 8월`) | 너비 9.86 |
| C | 주차 | 서버 계산 값 `N주차` | |
| D | 부서 | `REPORT_DEPARTMENT` | |
| E | 성명 | 직원 이름 (safeExcelText) | |
| F | 근무 유형 | 토/일 → `휴일근로`, 평일 → `연장근로` | |
| G | 시작일 | 근무일 날짜 셀 | `yyyy/mm/dd;@`, 너비 11.14 |
| H | 시간 | 시작 시간 셀 | `h:mm;@` |
| I | 종료일 | 종료 날짜 셀 (아래 자정 규칙) | `yyyy/mm/dd;@`, 너비 11.14 |
| J | 시간 | 종료 시간 셀 | `h:mm;@`, 너비 9.43 |
| K | 연장 근무 시간 | 수식 `J{r}-H{r}-M{r}` | `[h]:mm`, 너비 16.86 |
| L | 연장근무 | 시간 수 숫자 (`durationMinutes/60`, 0.5 허용) | 정수는 `0`, 소수는 `0.#`. 배경 `FFFFFF00`, 너비 9.86 |
| M | 공제 시간 | 0:00 고정 (기준 시트 규정상 평일 18시 기산이라 공제 없음) | `h:mm;@`, 너비 15.86 |
| N | 야간 근무 시간 | 빈 칸 | 너비 14.71 |
| O | 사유 | 기록의 업무 내용 (safeExcelText) | 너비 45.14 |
| P | 신청 일자 | 빈 칸 | `yyyy/mm/dd;@`, 너비 12.14 |
| Q | 결재 일자 | 빈 칸 | `yyyy/mm/dd;@`, 너비 12 |
| R | 결재 상태 | 빈 칸 | |
| S | 신청서 | 빈 칸 | |
| T | 비고 | 빈 칸 | 너비 17 |

명시 너비가 없는 열은 기본 너비를 쓴다(기준 파일도 auto).

### 데이터 행 테두리

- 내부: thin
- 바깥 박스: medium — A열 왼쪽, T열 오른쪽, 첫 데이터 행 위쪽, 마지막 데이터 행 아래쪽

### 날짜/시간 값 규칙

- 날짜 셀: 해당 날짜의 UTC 자정 `Date` (exceljs 관례)
- 시간 셀: 1899-12-30 기준 `Date` (Excel 시간 값)
- 자정 종료 규칙: 종료가 정확히 24:00(자정)이면 기준 파일 관례대로 종료일 = 근무일, 시간 = 24:00(값 1.0). 자정을 넘겨 끝나면(예: 01:00) 종료일 = 다음 날짜, 시간 = 실제 종료 시각
- `safeExcelText`는 텍스트 셀(성명, 사유)에만 적용. 날짜/시간/숫자 셀은 타입 셀이라 수식 주입이 성립하지 않는다

### 주차 계산 규칙

주는 월요일 시작. `1주차` = 1일부터 그 달의 첫 일요일까지, 이후 월~일 단위로 `2주차`, `3주차`, …. (한 달에 최대 6주차까지 나올 수 있다.)

## 시트 2: 집계 (정적 표)

기준 파일 피벗과 같은 배치의 값 표. 셀은 12pt, 이름 셀은 왼쪽 정렬. 테두리/배경 없음(기준 파일 피벗 영역과 동일).

```
A3: Sum of 연장근무   B3: 열 레이블
A4: (빈칸)           B4: {YY}년 {M}월   …  {요약열}4: {YY}년 {M}월 요약   {총합계열}4: 총합계
A5: 행 레이블         B5~: 1주차 … N주차
A6~: 직원 이름(가나다순) | 주차별 합계 | 월 합계 | 총합계
마지막 행: 총합계
```

- 주차 열은 그 달에 실제 존재하는 주차만 만든다(4~6개 가변)
- 값 = 해당 직원·주차의 L열(연장근무 시간 수) 합. 기록 없는 칸은 빈 칸(0 아님)
- 요약 열과 총합계 열은 월 범위가 한 달이라 값이 같다(기준 파일도 동일)
- 기록이 있는 직원만 표시
- 열 너비: A 15.43, 주차 열 6.14, 요약 12.57, 총합계 6.86

## 시트 3: 기준 (정적 텍스트)

기준 파일 그대로 B2~B5에 4줄:

```
B2: ※ 주 52시간제: 근로기준법상 1주 최대 연장 근로 시간은 12시간으로 제한됩니다. 
B3: ※ 평일 연장근로시 저녁 식사시간은 산정에서 제외하여야 함. 운영팀/ QA팀은 대부분 도시락을 먹으며 일하거나 식사를 안하고 근무하기 때문에 18시부터 기산으로 적용 → 직원에게 유리하게!
B4:    단, 휴일 근로시 점심시간은 확실히 제외
B5: ※ 근무유형 - 연장근로, 휴일근로
```

## 코드 변경 범위

- `apps/api/src/reports/excel.ts` — 전면 재작성. 입력을 `{ month, department, rows }`로 확장, 시트 3개 생성
- `apps/api/src/reports/reports.service.ts` — `excel()`이 month·부서를 함께 전달
- `apps/api/src/reports/reports.controller.ts` — 파일명 생성과 RFC 5987 Content-Disposition
- `apps/api/src/config/env.schema.ts` — `REPORT_DEPARTMENT` 추가 (Zod, 기본값 `IT개발팀`)
- 웹은 변경 없음: 다운로드 URL 그대로, 파일명은 Content-Disposition이 결정

## 빈 월 처리

기록이 없는 월도 정상 파일을 만든다: 이력 시트는 제목+헤더만(데이터 박스 테두리 없음), 집계 시트는 라벨 행(A3~A5, 주차 헤더)까지만 만들고 직원 행과 총합계 행은 생략, 기준 시트는 동일.
