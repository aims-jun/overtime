# AIMS 업무 연장 UI 디자인

## 목표

현재 서비스의 “늦은 기록”, “야근 기록” 표현과 감성적인 개인 기록장 인상을 제거한다. 회사명 AIMS가 선명하게 보이는 사내 업무 제품 `AIMS`로 리브랜딩하고, 모바일에서 빠르게 업무 연장 시간을 입력하고 확인하는 근태 도구로 재설계한다.

## 브랜드 방향

- 제품명: `AIMS`
- 주요 화면명: `업무 연장 내역`
- 핵심 행동: `업무 시간 추가`
- 내역 영역명: `WORK LOG`
- 대표 색상: 라임 `#D8FF45`
- 기본 잉크 색상: 딥 그린 `#172118`
- 보조 배경: 밝은 뉴트럴 그레이
- 인상: 강하고 간결한 사내 제품, 높은 대비, 장식보다 정보 우선

별도 회사 로고나 공식 색상은 사용하지 않는다. 텍스트 로고 `AIMS`와 위 색상 조합을 이 서비스의 자체 아이덴티티로 사용한다.

## 정보 구조

### 공통 헤더

모든 인증 후 화면의 왼쪽 상단에 `AIMS`를 표시한다. 오른쪽에는 현재 사용자, 관리자 이동 링크, 로그아웃을 배치한다. 모바일에서는 사용자 이름을 숨기되 관리자와 로그아웃 행동은 유지한다.

### 개인 홈

첫 화면은 다음 순서로 구성한다.

1. `WORK LOG · JULY` 형태의 현재 월 레이블
2. `업무 연장 내역` 제목
3. 이번 달 누적 시간을 보여주는 짙은 색 요약 카드
4. 라임색 `+ 업무 시간 추가` 버튼
5. `WORK LOG` 최근 기록 목록

입력 폼은 첫 화면에 항상 펼쳐두지 않는다. 사용자가 `업무 시간 추가`를 누르면 모바일에서는 화면 흐름을 방해하지 않는 인라인 패널이 열리고, 날짜·시작·종료·업무 내용을 입력한다. 저장 후 패널은 닫히고 월 합계와 목록이 갱신된다. 기존 기록의 수정 동작은 같은 패널을 수정 상태로 다시 연다.

### 기록 목록

기록은 날짜, 업무 내용, 시간 범위, 총 시간을 한 줄의 명확한 위계로 표시한다. `야근 사유`는 `업무 내용`, `예상 야근`은 `추가 근무 시간`으로 바꾼다. 삭제는 낮은 강조도의 보조 행동으로 유지하고 확인 대화상자를 사용한다.

### 로그인과 관리자

로그인 화면도 `AIMS` 텍스트 로고와 동일한 라임·딥 그린 체계를 사용한다. 안내 문구는 “회사 Google 계정으로 AIMS에 로그인하세요”로 바꾼다.

관리자 화면은 기능과 데이터 구조를 유지하되 동일한 색상, 타이포그래피, 직선적인 카드와 테이블 스타일을 사용한다. 화면명은 `업무 연장 현황`, CSV 행동은 `내역 다운로드`로 표현한다.

## 반응형 원칙

- 모바일 320px부터 입력과 기록 조회가 가능해야 한다.
- 모바일에서는 한 열, 데스크톱에서는 요약과 입력 패널을 넓게 사용한다.
- 주요 버튼의 터치 높이는 최소 44px로 유지한다.
- 고정 높이와 가로 스크롤을 피하고 긴 업무 내용은 자연스럽게 줄바꿈한다.
- 라임색은 주요 행동과 브랜드 표시에만 사용한다.

## 상태와 오류

로딩, 빈 목록, API 오류, 저장 중, 삭제 중 상태를 현재처럼 유지한다. 오류는 입력 필드와 가까운 위치에 명확한 한국어로 표시한다. 빈 목록은 `등록된 업무 연장 내역이 없습니다`로 표현하고 바로 위의 추가 버튼으로 행동을 유도한다.

## 구현 범위

백엔드 API, 데이터베이스 구조, Google 인증 방식, CRUD 동작은 변경하지 않는다. React 컴포넌트의 문구와 화면 구조, 전역 스타일, 로그인·개인·관리자 화면의 시각 체계만 변경한다. 시안에 없는 새 탭이나 근태 기능은 만들지 않는다.

## 검증

- 로그인, 개인 기록 생성·수정·삭제, 월 변경, 관리자 이동과 CSV 다운로드가 기존처럼 동작해야 한다.
- 기존 컴포넌트 테스트의 문구 기대값을 새 제품 용어로 갱신한다.
- 320px, 390px, 768px, 데스크톱 너비에서 겹침이나 가로 잘림을 시각적으로 확인한다.
- 키보드 포커스, 레이블, 오류 `role="alert"`, 버튼 최소 높이를 유지한다.
- 전체 웹 테스트, 린트, 타입 검사와 프로덕션 빌드를 통과해야 한다.
